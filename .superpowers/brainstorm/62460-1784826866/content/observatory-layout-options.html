/ADMIN · RUN OBSERVATORY

哪种空间关系更适合持续观测？

三种方案都使用真实产品语义：管理员默认仍看“我的 scope”，只有显式切换才读取所有 scope；从排班、技能、Fleet 或分享链接进入时，scope、run 与筛选条件会成为可分享的 URL 状态。

默认：我的 scope 显式：所有 scope 筛选可分享
A

可折叠运行轨 + 大详情画布

推荐
常态适合扫运行，按下“沉浸”后收起侧栏与全局导航，详情画布立即扩展。
平衡最好：保留上下文和高效切换，同时让 Timeline / Steps / Logs 获得明显更大的阅读面积。
/admin#/observatory?scope=mine&status=running,failed&run=run-7f29
