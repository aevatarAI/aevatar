1. NyxID 已写死

这个 demo 固定走 NyxID 主网，不需要在页面或本地再填 OpenAI API key。Host 内置的 Realtime proxy endpoint 是：

https://nyx.chrono-ai.fun/api/v1/proxy/s/llm-openai

NyxID 负责注入真正的 OpenAI credential；demo 只连当前 Mainnet Host 的 `/ws/voice`。

2. Agent 要有 voice module

点击“开始说话”时，demo 会自动创建或复用当前用户的 voice demo agent，并挂上 `voice_presence_openai` 模块。Mainnet Host 的上游 URL 已固定为 NyxID proxy；请求里的 NyxID bearer 只用于向 NyxID proxy 鉴权，不会作为 OpenAI key 暴露给浏览器。

`/ws/voice` 会按路由策略找到目标 agent；`/ws/voice/{actorId}` 是调试直连入口，需要登录用户具备 `voice:bypass` scope 或 admin/owner 角色。

3. 自动路由

demo 会调用 `POST /api/demo/voice/bootstrap`，在当前 NyxID scope 下登记 demo agent，并追加 `voice-demo` 路由规则。需要临时换目标 agent 时，也可以手动把 voice 请求路由到对应 actor；`scopeId` 使用当前登录用户或所属 scope，`actor_id` 换成目标 agent 的 actorId。

curl -X PUT "$MAINNET_HOST/api/scopes/$SCOPE_ID/chat-route-policy" \
  -H "authorization: Bearer $NYXID_TOKEN" \
  -H "content-type: application/json" \
  -d '{
    "default_target": {
      "forward_to_model": {
        "tool_set_ref": { "name": "voice.realtime" },
        "tool_choice_hint": {
          "tool_name": "aevatar_invoke_gagent",
          "prefilled_arguments": {
            "actor_id": "YOUR_AGENT_ACTOR_ID",
            "voice_module_name": "voice_presence_openai"
          }
        }
      }
    },
    "rules": [
      {
        "rule_id": "voice-demo",
        "priority": 100,
        "match": { "source_kind": "CHAT_SOURCE_KIND_VOICE" },
        "action": {
          "forward_to_model": {
            "tool_set_ref": { "name": "voice.realtime" },
            "tool_choice_hint": {
              "tool_name": "aevatar_invoke_gagent",
              "prefilled_arguments": {
                "actor_id": "YOUR_AGENT_ACTOR_ID",
                "voice_module_name": "voice_presence_openai"
              }
            }
          }
        },
        "description": "route browser voice demo to the mainnet agent"
      }
    ]
  }'

4. 打开 demo

线上部署后访问当前 Mainnet Host 的：

/demo/voice

本地调试启动 Mainnet Host 后访问：

http://127.0.0.1:5080/demo/voice

浏览器会请求麦克风权限。连接成功后直接说话，agent 的音频回复会从当前页面播放。
