1. NyxID 已写死

这个 demo 固定走 NyxID 主网，不需要在页面或本地再填 OpenAI API key。Host 内置的 Realtime proxy endpoint 是：

https://nyx.chrono-ai.fun/api/v1/proxy/s/llm-openai

NyxID 负责注入真正的 OpenAI credential；demo 调试直连当前 Mainnet Host 的 `/ws/voice/{actorId}`。

2. Agent 要有 voice module

点击“开始说话”时，demo 会自动创建或复用当前用户的 voice demo agent，并挂上 `voice_presence_openai` 模块。Mainnet Host 的上游 URL 已固定为 NyxID proxy；请求里的 NyxID bearer 只用于向 NyxID proxy 鉴权，不会作为 OpenAI key 暴露给浏览器。

普通 `/ws/voice` 不再从 `tool_choice_hint` 推导目标 agent；`/ws/voice/{actorId}` 是调试直连入口，需要登录用户具备 `voice:bypass` scope 或 admin/owner 角色。

3. 调试直连

demo 会调用 `POST /api/demo/voice/bootstrap`，在当前 NyxID scope 下登记 demo agent，并返回可用于调试直连的 `actor_id` 与 `voice_module_name`。普通 `/ws/voice` 会对 `ForwardToModel` fail closed；临时换目标 agent 时使用显式 bypass 路径。

wss://MAINNET_HOST/ws/voice/YOUR_AGENT_ACTOR_ID?voice_module_name=voice_presence_openai

4. 打开 demo

线上部署后访问当前 Mainnet Host 的：

/demo/voice

本地调试启动 Mainnet Host 后访问：

http://127.0.0.1:5080/demo/voice

浏览器会请求麦克风权限。连接成功后直接说话，agent 的音频回复会从当前页面播放。
